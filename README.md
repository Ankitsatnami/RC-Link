# RC Link

**RC Link** is a professional, universal Android controller application designed for ESP32-based robotics, IoT, automation, and custom experimental projects. Connect over Bluetooth Classic, BLE, or Wi-Fi to seamlessly operate a massive variety of robotics hardware using beautifully designed animated dashboards.

## 📥 Download the App (APK)

We use GitHub Actions to automatically build the latest version of the app upon every update.

[![Build APK](https://github.com/Ankitsatnami/RC-Link/actions/workflows/android.yml/badge.svg)](https://github.com/Ankitsatnami/RC-Link/actions/workflows/android.yml)

**To download the latest APK:**
1. Navigate to the **[Actions Tab](https://github.com/Ankitsatnami/RC-Link/actions/workflows/android.yml)**.
2. Click on the latest successful workflow run.
3. Scroll down to the **Artifacts** section at the bottom.
4. Click on **RC-Link-App** to download the generated APK zip file. Extract it and install it on your Android device!

## Features (In Development)

* **Universal Connection System:** Support for Bluetooth Classic, BLE, and Wi-Fi (TCP/UDP).
* **Multiple Dashboards:** Prebuilt gorgeous controllers for RC Cars, Smart Home Automation, RGB LEDs, Scrolling Drones, and Boats.
* **Command Mapping Engine:** Map standard UI inputs to custom commands interpretable by any ESP32 project.
* **Professional UI:** Native Jetpack Compose interface with glowing indicators, shadows, and smooth 60fps animations.
